# VX-Underground PDF Dataset

This catalog contains a test set of PDF files obtained from the VX-Underground collection. The dataset includes just over 8,000 PDF documents, consisting mainly of articles from The Old New Thing.

## Purpose

This dataset is intended for testing and development within the VX-RAG system, a Retrieval-Augmented Generation (RAG) tool designed to process and search large documents from VX-Underground.
